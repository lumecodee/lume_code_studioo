Tipos de datos en JavaScript

  • 1. String — Cadena de texto

    • permite almacenar texto, como nombres, direcciones o mensajes. Se escribe entre comillas simples o dobles, o con acentos graves.

  • Number — Número

    • representa números enteros y decimales. Permite realizar operaciones matemáticas.

  • Boolean — Verdadero o falso

    • representa dos valores posibles: true (verdadero) y false (falso).

  • Array — Arreglo

    • es una estructura que permite almacenar varios elementos dentro de una misma variable.

  • Object — Objeto

    • permite agrupar información relacionada mediante propiedades que tienen un nombre y un valor.

  • if — Si

    • permite ejecutar un bloque de código únicamente cuando una condición es verdadera

  • else — Si no

    • permite ejecutar un bloque alternativo cuando la condición del if es falsa

  • for — Para

    • es un bucle que permite repetir un bloque de código una determinada cantidad de veces, según sus condiciones.

  • while — Mientras

    • repite un bloque de código mientras una condición sea verdadera.

  • function — Función

    • es un bloque de código reutilizable que puede recibir datos, realizar operaciones y devolver un resultado.

  • array — Arreglo

    • además de almacenar varios elementos, los arrays ofrecen métodos para trabajar con ellos.

  • object — Objeto

    • los objetos agrupan propiedades y también pueden contener funciones, que cuando pertenecen a un objeto se llaman métodos.

  • DOM y Model

    • el DOM es una representación estructurada del documento HTML que el navegador crea para que JavaScript pueda acceder a sus elementos y modificarlos

  • Model — Modelo

    • la palabra model significa «modelo». En programación puede referirse a una representación de los datos o de una entidad del sistema.
