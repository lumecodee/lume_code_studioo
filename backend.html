Que es un Servidor?

un servidor es una computadora o programa que recive solicitudes y prooporciona respuestas o servicios a otros dispositivos

Un servidor puede encargarse de distintas cosas:

  • Servir paginas web
  • Entregar datos
  • Autenticar Usuarios
  • Comunicarse con una bace de datos
  • Ejecutar logica de negocios

    • Tipos de servidores

    1. Servidor web

      2. Recibe solicitudes HTTP y entrega contenido web

    2. Servidor de aplicaciones

      3. Ejecuta la lógica de una aplicación.

    3. Servidor de bace de datos
      4. Gestiona el almacenamiento y las consultas de datos.
    4. Servidor de Archivos

      5. Permite almacenar y compartir archivos.

    5. Servidor DNS

      6. Ayuda a traducir nombres de dominio a direcciones IP.

    6. Servidor de correo

      7. Gestiona el envío, la recepción o el almacenamiento de correos electrónicos.
